# মোহাম্মদপুর মাদকবিরোধী অভিযান (Mohammadpur Anti-Drug Initiative)
### অবস্থান: মোহাম্মদপুর ইউনিয়ন, পাঁচবিবি উপজেলা, জয়পুরহাট জেলা (২৫.২২৪৭° N, ৮৯.১০৬২° E)
**মূল স্লোগান:** *“মাদককে না বলি, মাদকমুক্ত সমাজ গড়ি — হয় মাদক ছাড়, না হয় মোহাম্মদপুর ছাড়”*

---

## 🌟 ওভারভিউ (Project Overview)
এই প্ল্যাটফর্মটি জয়পুরহাটের পাঁচবিবি উপজেলার **মোহাম্মদপুর ইউনিয়ন** এবং সীমান্ত করিডোর এলাকাকে ট্যাপেন্টাডল, বুপ্রেনরফিন/কুপিজেসিক ইনজেকশন, ফেনসিডিল ও অবৈধ মাদকমুক্ত করার একটি পূর্ণাঙ্গ নাগরিক প্রতিরোধ প্ল্যাটফর্ম।

### মূল প্রযুক্তি (Tech Stack)
* **Frontend:** HTML5, Modern Vanilla CSS3 (Glassmorphism & Dynamic Themes), JavaScript (ES Modules), Vite
* **Assets:** কাস্টম ভেক্টর সিল/এমব্লেম, ফিল্ড র‍্যালি ও নিরাময় কাউন্সেলিং ভিজ্যুয়াল
* **Backend Ready:** Laravel REST API ইন্টিগ্রেশনের জন্য সম্পূর্ণ প্রস্তুত

## 🚀 লোকালি ওয়েবসাইট চালানোর নিয়ম (Run Locally)

প্রজেক্ট ফোল্ডারে প্রবেশ করে কমান্ড প্রম্পট বা পাওয়ারশেলে চালান:
```bash
cd C:\Users\nahid\.gemini\antigravity-ide\scratch\mohammadpur-anti-drug

# ডিপেন্ডেন্সি ইনস্টল (যদি ইতিমধ্যে না থাকে)
npm install

# লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```
ব্রাউজারে খুলুন: **`http://localhost:5173/`**

## 🛡️ প্রধান প্রধান ফিচারসমূহ (Key Features)

1. **১০০% গোপন তথ্য প্রদান বক্স (Zero-Log Whistleblower Box):**
   - কোনো নাম, মোবাইল নম্বর বা আইপি অ্যাড্রেস সংগ্রহ করা হয় না।
   - **EXIF মেটাডাটা স্ক্রাবার:** আপলোডকৃত ছবির ক্যামেরা বা জিপিএস মেটাডাটা স্বয়ংক্রিয়ভাবে মুছে ফেলা হয়।
   - ইউনিক রেফারেন্স কোড তৈরি (`MP-PANCH-2026-XXXX`)।

2. **রিপোর্ট ট্র্যাকিং টুল (Live Report Progress Tracker):**
   - সাধারণ নাগরিকরা তাদের সিক্রেট কোড দিয়ে রিপোর্টের ৪-ধাপের অগ্রগতি দেখতে পারেন।

3. **সীমান্ত ও ইউনিয়ন ক্রাইম ওয়াচ রাডার (Interactive Hotspot Radar):**
   - মোহাম্মদপুর বাজার, শ্রীমন্তপুর ও ধরন্জী সীমান্ত, রতনপুর, চেঁচড়া, বাগজানা, পাঁচবিবি রেলস্টেশন ইত্যাদির লাইভ স্ট্যাটাস।
   - এক ক্লিকে উক্ত এলাকার জন্য সরাসরি রিপোর্ট করার সুবিধা।

4. **জরুরি হটলাইন ডিরেক্টরি (Emergency Helplines):**
   - পাঁচবিবি থানা ওসি (`০১৭১৩-৩৭৪০৮৬`)
   - থানা ডিউটি অফিসার (`০১৮৬৫-০২০২২৭`)
   - বিজিবি ২০ ব্যাটালিয়ন জয়পুরহাট (`০১৭৬৯-৬১২৩৫০`)
   - র‍্যাব-৫ জয়পুরহাট ক্যাম্প (`০১৭৭৭-৭১০৫৩৩`)
   - মাদকদ্রব্য নিয়ন্ত্রণ অধিদপ্তর (ডিএনসি) হটলাইন (`১৬১১৬`)
   - জাতীয় জরুরি সেবা (`৯৯৯`)
   - পাঁচবিবি উপজেলা স্বাস্থ্য কমপ্লেক্স (`০১৭৩০-৩২৪৩১২`)

5. **মাদক নিরাময় ও পুনর্বাসন উইং (Rehab & Life Recovery):**
   - ৫-প্রশ্নের ক্লিনিক্যাল স্ক্রিনিং টেস্ট (Drug Dependency Assessment Quiz)।
   - জয়পুরহাট ও উত্তরাঞ্চলের অনুমোদিত রিহ্যাব সেন্টার তালিকা।
   - সম্পূর্ণ গোপন মানসিক স্বাস্থ্য কাউন্সেলিং রিকোয়েস্ট ফর্ম।

6. **নাগরিক স্কোয়াড ও ভলান্টিয়ার নেটওয়ার্ক (Volunteer Squad):**
   - ওয়ার্ডভিত্তিক ভলান্টিয়ার রেজিস্ট্রেশন (ওয়ার্ড ১-৬)।

7. **ফ্লোটিং এসওএস বাটন (Floating Quick Dial SOS Widget):**
   - স্ক্রিনের নিচে ভাসমান রেড এসওএস বাটন, যাতে এক ট্যাপে সরাসরি জরুরি নম্বরে কল করা যায়।

## 🔌 Laravel ব্যাকএন্ড ইন্টিগ্রেশন আর্কিটেকচার (Ready for Laravel)

ফ্রন্টএন্ডের সকল ফর্ম (`Whistleblower`, `Tracking`, `Volunteer`, `Counselor`) এমনভাবে তৈরি করা হয়েছে যা নিচের লারাভেল এন্ডপয়েন্টগুলোতে সরাসরি ডেটা পাঠাতে সক্ষম:

* `POST /api/reports` — এনক্রিপ্টেড গোপন রিপোর্ট জমা নেওয়া
* `GET /api/reports/track/{code}` — রেফারেন্স কোড দিয়ে স্ট্যাটাস যাচাই
* `POST /api/volunteers` — ওয়ার্ডভিত্তিক স্বেচ্ছাসেবক নিবন্ধন
* `POST /api/counseling` — কাউন্সেলিং অ্যাপয়েন্টমেন্ট অনুরোধ
* `GET /api/zones` — রিয়েলটাইম জোনের স্ট্যাটাস ও আপডেট ফেচ করা
